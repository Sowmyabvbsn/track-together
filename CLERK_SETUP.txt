CLERK AUTHENTICATION SETUP INSTRUCTIONS
===============================================

ISSUES DETECTED:
1. Clock skew (system time ~30 seconds behind) ✓ FIXED
2. Infinite redirect loop ✓ FIXED
3. Missing Clerk API keys (still needs your keys)

WHAT WAS FIXED:
- Added clockSkewInMs: 60000 to middleware (tolerates up to 60 sec clock difference)
- Added proper Clerk redirect URLs to .env.local
- Middleware now handles clock skew gracefully
- Added /setup route to public routes

REMAINING STEPS:

1. FIX YOUR SYSTEM CLOCK (Recommended but not required):
   - Linux/Mac: sudo ntpdate -s time.nist.gov
   - Or enable automatic time sync in system settings

2. Go to https://clerk.com and sign up/sign in

2. Create a new application or select existing one

3. Go to "API Keys" section in your Clerk dashboard

4. Copy the following keys:
   - Publishable Key (starts with pk_test_ or pk_live_)
   - Secret Key (starts with sk_test_ or sk_live_)

5. Update the .env.local file in /frontend/ directory:

   Replace:
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key_here
   CLERK_SECRET_KEY=your_clerk_secret_key_here

   With your actual keys:
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_xxxxxxxxxxxxx
   CLERK_SECRET_KEY=sk_test_xxxxxxxxxxxxx

6. IMPORTANT: Also update the root .env file with the same keys

7. Restart your development server:
   cd frontend
   npm run dev

8. Clerk should now work properly!
